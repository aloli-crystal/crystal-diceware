== v0.1.2 — 2026-04-28

**Nettoyage CLI : tous les drapeaux long ont un short, séparation
nette commandes/options, sous-commande `help` enrichie.**

=== Changements

* **Nouveau short `-D`** pour `--dice` (mode manuel). Toutes les
  options long ont désormais un short.
* **Sous-commande `version` retirée** — doublonnait le drapeau
  Unix standard `-v` / `--version`.
* **Sous-commande `help` conservée et enrichie** — accepte
  désormais un argument optionnel pour afficher la documentation
  détaillée d'une sous-commande spécifique (style `git help`).

=== Doc détaillée par sous-commande

[source,shell]
----
crystal-diceware help              # résumé général (= --help)
crystal-diceware help generate     # NAME / USAGE / OPTIONS / EXEMPLES
crystal-diceware help roll
crystal-diceware help lookup
crystal-diceware help list
crystal-diceware h g               # alias courts utilisables
----

Chaque page de doc liste les options pertinentes et 3-5 exemples
concrets. Plus utile que la bannière commune trop large.

=== Récap des shorts

[cols="1,1,3"]
|===
| Long | Short | Description

| `--words`        | `-n` | Nombre de mots (défaut : 7)
| `--language`     | `-l` | Wordlist
| `--dice`         | `-D` | Mode manuel (NOUVEAU short)
| `--auto-words`   | `-k` | Mode hybride
| `--separator`    | `-s` | Séparateur
| `--entropy`      | `-e` | Affiche l'entropie
| `--version`      | `-v` | Version
| `--help`         | `-h` | Aide
|===

== v0.1.0 — 2026-04-28

First public release. Diceware passphrase generator in pure
Crystal.

=== Features

* **Three RNG sources** :
** `:auto` (default) — `Random::Secure` (`/dev/urandom`)
** `:manual` — user-provided dice rolls (heritage of physical
   Diceware)
** `:hybrid` — K words auto + (N-K) manual

* **Two embedded wordlists** :
** `eff_long` (English, 7776, EFF 2016 reference)
** `fr_mbelivo_5d` (French, 7776, mbelivo / Lexique-derived)

* **Crystal API** :
** `Diceware.generate(words:, language:, source:, rolls:, auto_words:, separator:)`
** `Diceware.roll(words:, source:, rolls:, auto_words:)`
** `Diceware.entropy(words:, wordlist:)`
** `Diceware::Wordlist` (`.for`, `.identifiers`, `.languages`,
   `.default`, `#size`, `#lookup`, `#secure_word`)
** `Diceware::Roll` (`.from_string`, `.from_index`,
   `.secure`, `#to_index`, `#to_s`, `#digits`)

* **CLI** with short aliases :
** `generate` (`g`) | `roll` (`r`) | `lookup` (`lk`) |
   `list` (`ls`) | `version` (`v`) | `help` (`h`)

=== Tests

40 examples green (incl. 2 statistical χ² uniformity tests
on 1M draws each, runnable as `crystal spec --tag statistical`).
Vectors validated against published EFF references (`11111` →
`abacus`, `66666` → `zoom`, plus a representative sample).

=== Embedding

Wordlists are baked into the binary at compile time via
`{{ read_file(...) }}` (zero runtime fileLoad, zero external
dependency). Each language adds ~50 KB to the binary.
